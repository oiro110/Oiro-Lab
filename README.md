# Oiro Lab

Androidアプリ・Windowsソフト・拡張機能を紹介する、静的サイトです。
GitHub Pagesでの公開を想定しており、サーバーやビルドは使いません。

## 機能

- 作品の一覧表示(種類ごとにグループ化)
- キーワード検索(スペース区切りのAND検索。全角/半角、大文字/小文字、ひらがな/カタカナの違いは無視)
- 種類(Androidアプリ / Windowsソフト / 拡張機能)と状況(公開中 / 開発中 / 開発予定)での絞り込み
- 作品ごとの詳細表示(概要、特徴、スクリーンショット、更新履歴、リンク)
- 詳細表示のURL共有(`#/作品ID`)
- スマホ表示、ダークモードに対応

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | ページ本体(ヘッダー、検索欄、フッターのリンクなど) |
| `style.css` | デザイン(配色は先頭の `:root` に集約) |
| `app.js` | 一覧表示・検索・絞り込み・詳細表示の処理 |
| `works.js` | 作品データ |
| `favicon.svg` | ブラウザのタブに表示されるアイコン |

## 作品データ(`works.js`)

`window.OIRO_WORKS` の配列に、作品1件につきオブジェクトを1つ記載します。

| 項目 | 内容 |
| --- | --- |
| `id` | 半角英数字とハイフンの識別子(作品ごとに重複不可)。詳細表示のURL `#/id` にも使用 |
| `name` | 作品名 |
| `platform` | `"android"` / `"windows"` / `"extension"` |
| `status` | `"released"`(公開中) / `"developing"`(開発中) / `"planned"`(開発予定) |
| `kind` | 種類の表示(例: パズルゲーム、業務用) |
| `summary` | 一覧に表示する短い説明(2行程度) |
| `tags` | 検索用キーワードの配列(別名や略称も記載可。例: 「ボイチェン」) |
| `description` | 概要の文章(段落ごとの配列) |
| `features` | 主な特徴(箇条書きの配列。空でも可) |
| `notes` | ご案内(広告・データの扱いなど。省略可) |
| `price` | 料金の表示(省略可) |
| `released` / `updated` | リリース日 / 最終更新日。`"2026-11-21"` 形式(省略可) |
| `icon` | アイコン画像のURLまたは相対パス(省略時は種類ごとの線アイコン) |
| `screenshots` | スクリーンショット画像のURLまたは相対パスの配列(省略可) |
| `links` | ボタンのリンク。`{ label, url, kind }` の配列。1つ目が主ボタン、`kind: "privacy"` はプライバシーポリシー用の表示 |
| `history` | 更新履歴。`{ date, text }` の配列(省略可) |

### 表示のルール

- 一覧は、種類(Android → Windows → 拡張機能)ごとにグループ化されます。
- グループ内の並びは、状況(公開中 → 開発中 → 開発予定)、最終更新日の新しい順、`works.js` の記載順の優先順位です。
- `links` が空で、状況が開発中・開発予定の作品には、準備中の案内文が表示されます。
- 検索対象は、作品名・概要・特徴・`tags`・種類・状況です。

## 画像

- 現在のアイコンとスクリーンショットは、Google Playに掲載されている画像のURLを参照しています。
- 画像を読み込めない場合、アイコンは線アイコンに、スクリーンショットは非表示に切り替わります。
- リポジトリ内の画像を使う場合は、`icon` や `screenshots` に `"images/xxx.png"` のような相対パスを指定します。

## 外部サービス

- 見出しのフォントに Google Fonts(Zen Maru Gothic)を読み込んでいます(`index.html` の `fonts.googleapis.com` を含む行)。未読み込み時は端末の標準フォントで表示されます。
